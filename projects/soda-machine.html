Arduino Soda Dispenser

A Bluetooth-controlled soda dispensing system combining electronics, mechanisms and 3D-printed components.

ArduinoBluetoothDC PumpMechanical Integration

Project Overview

Built an Arduino-controlled beverage dispenser that receives commands from a smartphone over Bluetooth. A repurposed printer mechanism moves the cup while a DC pump provides the pressure used for dispensing.

Key Features

  • Bluetooth smartphone control.
  • Repurposed printer carriage for cup positioning.
  • DC pump-based dispensing mechanism.
  • Custom 3D-printed cup holder.
