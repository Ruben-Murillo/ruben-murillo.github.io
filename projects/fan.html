Arduino Fan Machine

An automatic fan capable of horizontal and vertical motion with both manual and automatic control.

ArduinoDC MotorsTemperature/HumidityLCD

Project Overview

Built a two-axis fan controlled by an Arduino. DC motors provide horizontal and vertical motion, while a temperature/humidity sensor feeds environmental data to the controller and a local LCD.

Key Features

  • Manual and automatic operating modes.
  • Temperature and humidity measurement.
  • LCD feedback for environmental data.
  • Arduino-based motor control and system logic.
