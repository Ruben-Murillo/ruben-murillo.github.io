Raspberry Pi 5 Linux Systems Lab

A practical home infrastructure lab used to build Linux, networking, storage and automation experience.

LinuxDockerSamba/SMBTailscaleBash/Python

What I Built

Configured a Raspberry Pi 5 as a Linux server for self-hosted services and remote access. The system uses Docker-based applications, SMB network storage and Tailscale for secure remote connectivity.

Engineering Work

  • Configured and administered Linux services, permissions and storage.
  • Built Samba/SMB shares for Windows and mobile access.
  • Used Tailscale for remote networking and service access.
  • Managed Dockerized services and application updates.
  • Created Bash/Python workflows for media import, file handling and duplicate-management tasks.
  • Troubleshot power recovery, service availability, storage expansion and network access.

Why It Matters

This project keeps Linux and scripting skills current while providing a foundation for future ROS2 work on Raspberry Pi hardware.

Planned evolution: repurpose this experience into a ROS2 autonomous mobile robot using a Pi 5, microcontroller, encoders, IMU and LiDAR.
