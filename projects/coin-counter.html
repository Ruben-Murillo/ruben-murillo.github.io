Arduino Coin Counter

A coin counting and sorting system using optical sensing and an LCD interface.

ArduinoIR SensorsLCDEmbedded Logic

Project Overview

Designed an Arduino-controlled coin counter/sorter using four IR sensors to detect coins as they pass through the mechanism.

Key Features

  • Four IR sensors for coin detection.
  • 20×4 LCD for denomination counts and total monetary value.
  • Embedded logic for detection and running totals.
