Voltron V3 Autonomous Go-Kart

Kennesaw State University senior project (Aug 2022–May 2023). The team renovated and improved an autonomous racing go-kart with the goal of increasing reliability, speed and usability.

ROS2C++PythonOdometryLocalization

Project Overview

The project continued development of Kennesaw State University’s EVT autonomous racing go-kart. Major work included steering improvements, sensor upgrades and a new wheel-odometry system intended to improve localization reliability.

My Contributions

  • Developed and tested the operator HMI in Python.
  • Implemented wheel-odometry calculations in C++ and ROS2.
  • Supported system operation, test procedure development and vehicle-level troubleshooting.
  • Helped integrate wheel-speed data into localization to reduce the effects of GPS drift, vibration and other disturbances.

System Improvements

The project upgraded the kart’s sensing stack with a higher-resolution LiDAR and an RGB-D camera. The steering system was also redesigned around a belt-driven gearbox and brushless motor to improve precision and reduce backlash.
